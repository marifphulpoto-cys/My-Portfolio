# 🛡️ Cyber Security Specialist • VAPT & Report Writer • Web Developer Portfolio

An elite, high-performance portfolio website engineered for a **Cybersecurity Student & Freelancer** specializing in:
- **Vulnerability Assessment and Penetration Testing (VAPT)**
- **Executive & Technical Security Report Writing (CVSS v3.1)**
- **Secure Full-Stack Web Development**

---

## ⚡ What Makes This Unique

1. **Cyber-Lab White Theme (Default):**
   - Clean, crisp high-tech white laboratory aesthetic with HUD corner brackets, subtle cyber grid overlay, and cyber emerald (`#059669`) / threat crimson (`#dc2626`) accents.
   - Built-in **Theme Switcher** in the header to toggle between **Cyber White (Lab)** and **Dark Ops (Night)**.
2. **Advanced, Non-Trivial Cyber Animations:**
   - **Interactive Cyber Constellation & Particle Canvas:** Real-time particle nodes that react and connect glowing cyber vectors directly to the user's mouse cursor.
   - **Hacker Text Scrambler / Decoder:** Dynamic cipher animation that scrambles characters through random runes and hex codes before decoding into readable words.
   - **Interactive Radar Sonar Threat Detector:** Real-time rotating radar sweep detecting and pinging simulated threat anomalies with pulsating blips.
   - **Laser Scan-Line Effect:** High-tech laser sweep animation traversing cards on hover.
   - **3D Parallax Tilt Cards:** Service and project cards smoothly pitch and tilt following 3D mouse physics.
3. **Live Interactive VAPT Target Scanner:**
   - Visitors can enter any target URL and click **"Initiate VAPT Audit"** to watch a simulated penetration test run in real-time with step-by-step terminal logs, OWASP checks, progress bar, and CVSS score calculation.
4. **Interactive Security Report Modal:**
   - Real-world VAPT Audit Report viewer featuring Executive Summaries, CVSS v3.1 vector calculations, verified exploit Proof-of-Concepts (PoCs), and developer remediation patches.
5. **Interactive Cyber CLI Terminal:**
   - Fully functional hacker terminal supporting security commands: `vapt`, `scan`, `report`, `tools`, `skills`, `clear`.
6. **1-File Centralized Configuration ([`js/data.js`](js/data.js)):**
   - Update your name, services, CVE findings, skills, projects, and contact info in a single clean config file!

## 🚀 How to Run & Preview

### Option 1: Instant Browser View (Zero Setup)
**Double-click** [`index.html`](index.html) to open directly in any browser.

### Option 2: Local HTTP Server
Double-click [`start_server.bat`](start_server.bat) or run:
```powershell
python -m http.server 3000
```
Open **`http://localhost:3000`** in your browser.

## 🛠️ Personalizing Your Info

Open 👉 **[`js/data.js`](js/data.js)** to customize:
- `portfolioData.profile`: Your name, role, email, and social profiles.
- `portfolioData.services`: Your custom VAPT and security offerings.
- `portfolioData.projects`: Your penetration testing engagements, bug bounty writeups, and web builds.
- `portfolioData.sampleReport`: Your sample executive summary and findings.
